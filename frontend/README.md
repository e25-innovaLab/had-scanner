# Had Scanner - Frontend

Accessibility scanner for teaching materials. A teacher uploads a PDF or pastes text, gets an orientative diagnosis across six dimensions, and reviews AI-proposed adaptations one by one.

## Stack

- Next.js 16 (App Router) + React 19 + TypeScript strict
- Tailwind CSS 4
- [shadcn/ui](https://ui.shadcn.com) for UI primitives (Base UI, accessible by default). See `CONTRIBUTING.md` for how to add components.
- npm

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Structure

```text
src/
  app/            routes: / (upload), /diagnosis, /adaptation
  components/ui/  shadcn primitives, generated by the CLI
  features/       one folder per module: upload, diagnosis, adaptation
  fixtures/       typed sample data that stands in for the API
  lib/            shared helpers (cn)
  types/          shared contract between modules
```
